Open-source & third-party notices

NidoBox acknowledges the open-source libraries and system frameworks used across its macOS, Windows 10/11, and Direct Desktop editions. Included components depend on the specific platform package installed.

1. Apple Mac App Store Edition (com.nido.box.mas)

The Mac App Store edition is built in native Swift 6 against official Apple macOS system frameworks (SwiftUI, AppKit, ScreenCaptureKit, Vision, Speech, AVFoundation, Network, DiskArbitration) and dynamically links macOS's built-in libarchive. No GPL or third-party kernel/FUSE binaries are bundled.

  • libarchive (macOS system dynamic library) — BSD 2-Clause License. Copyright © Tim Kientzle and contributors (libarchive.org).

2. Windows 10/11 Edition (com.nido.box)

The Windows workbench combines a Rust backend and React interface built on permissively licensed open-source packages:

Component License Upstream project
Tauri v2, wry, tao MIT OR Apache-2.0 github.com/tauri-apps/tauri
React & React DOM MIT License github.com/facebook/react
Lucide Icons ISC License github.com/lucide-icons/lucide
image, zip, sevenz-rust, tar, flate2 MIT / Apache-2.0 Rust crates ecosystem (crates.io)
qrcode, rqrr, tiny_http, serde MIT OR Apache-2.0 Rust crates ecosystem (crates.io)
windows-rs MIT OR Apache-2.0 github.com/microsoft/windows-rs

3. Direct macOS Installer Edition only (.dmg outside Mac App Store)

Only the standalone Direct macOS .dmg edition bundles separate user-space command-line utilities for external NTFS volume mounting (excluded from the Mac App Store edition):

  • Tuxera NTFS-3G (ntfs-3g, ntfsfix, ntfslabel, mkntfs, libntfs-3g) — GNU General Public License v2 (GPLv2) / GNU Lesser General Public License v2 (LGPLv2), executed as an unmodified separate process. Upstream source: github.com/tuxera/ntfs-3g. Written inquiries for corresponding GPL source code of bundled unmodified binaries may also be sent to support@nido-holdings.com.
  • FUSE-T (libfuse-t.dylib, go-nfsv4) — Distributed under the FUSE-T license terms preserving upstream copyright notices (github.com/macos-fuse-t/fuse-t).

Giấy phép mã nguồn mở & thông báo bên thứ ba

NidoBox trân trọng ghi nhận bản quyền của các thư viện mã nguồn mở và framework hệ thống sử dụng trên từng nền tảng phát hành.

1. Phiên bản Apple Mac App Store (com.nido.box.mas)

Phiên bản Mac App Store được biên dịch bằng Swift 6 gốc dựa trên các framework chính thức của macOS (SwiftUI, AppKit, ScreenCaptureKit, Vision, Speech, AVFoundation, Network, DiskArbitration) và liên kết động với libarchive tích hợp sẵn của macOS. Tuyệt đối không đóng gói kèm bất kỳ tệp thực thi GPL hay FUSE nào.

  • libarchive (Thư viện hệ thống macOS) — Giấy phép BSD 2-Clause. Bản quyền © Tim Kientzle và các cộng tác viên (libarchive.org).

2. Phiên bản Windows 10/11 (com.nido.box)

Phiên bản Windows sử dụng nhân xử lý Rust kết hợp giao diện React từ các gói mã nguồn mở cấp phép rộng rãi (MIT / Apache-2.0 / ISC):
